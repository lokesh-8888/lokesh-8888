### 🧾 RazorLedger AI — AI-Powered Financial Reconciliation

An AI-assisted financial reconciliation platform designed to identify transaction
mismatches, classify exceptions, and assist with automated resolution while
maintaining a human-review workflow.

**Tech Stack**

<p align="left">

<img src="https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white" alt="Java"/>

<img src="https://img.shields.io/badge/Spring%20Boot-6DB33F?style=for-the-badge&logo=springboot&logoColor=white" alt="Spring Boot"/>

<img src="https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white" alt="Python"/>

<img src="https://img.shields.io/badge/FastAPI-009688?style=for-the-badge&logo=fastapi&logoColor=white" alt="FastAPI"/>

<img src="https://img.shields.io/badge/React-61DAFB?style=for-the-badge&logo=react&logoColor=black" alt="React"/>

<img src="https://img.shields.io/badge/PostgreSQL-4169E1?style=for-the-badge&logo=postgresql&logoColor=white" alt="PostgreSQL"/>

<img src="https://img.shields.io/badge/Docker-2496ED?style=for-the-badge&logo=docker&logoColor=white" alt="Docker"/>

</p>

#### 🔍 Key Features & Implementation

- Designed a multi-service architecture using **Spring Boot**, **FastAPI**,
  and **React**.
- Built transaction reconciliation workflows for comparing and matching
  financial records.
- Implemented exception detection for transactions that cannot be
  automatically reconciled.
- Developed an AI-assisted workflow for resolving reconciliation exceptions.
- Added a **human-review workflow** for cases requiring manual verification.
- Created synthetic transaction datasets for controlled system evaluation.
- Isolated ground-truth records to evaluate automated decisions accurately.
- Built a benchmark runner for measuring reconciliation and AI performance.
- Evaluated the system using precision, recall, F1 score, match rate, and
  resolution metrics.
- Containerized the complete application using **Docker Compose**.
- Designed communication between services through structured REST APIs.
- Separated AI decision-making from the core reconciliation engine for
  independent evaluation.
